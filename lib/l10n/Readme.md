# Localization in Flutter

This document provides guidance on how to manage localization in your Flutter application.

## Generating Localization Files

Before running your app, ensure to generate the localization files by executing the following command:

```bash
flutter gen-l10n
```

This command will create the necessary localization files based on your configuration.
